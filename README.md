## 📝 Problem-Solving Rules

1. Read and understand the problem.
2. Try to solve it independently.
3. Spend 20–40 minutes thinking.
4. If stuck, take a small hint.
5. Implement the solution myself.
6. Analyze Time & Space Complexity.
7. Add revision notes.
8. Revisit difficult problems regularly.
